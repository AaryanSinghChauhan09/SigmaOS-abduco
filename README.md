# SigmaOS abduco

This repository is currently a minimal `no_std` component identity scaffold. Its library exposes a `Component` whose name is `SigmaOS-abduco`.

It does not implement the upstream abduco terminal session manager or session attach/detach behavior. The repository name is not evidence of feature compatibility.

## Build

```sh
cargo check --lib
```
